# Iheb Lamouchi — Portfolio

Bilingual Data Science & AI portfolio with English/French switching, light/dark themes, subtle data-network animation, selected projects, and a downloadable CV.

Static HTML, CSS, and JavaScript. GitHub Pages publishes from `main` at the repository root; `.nojekyll` keeps the site as plain static files.

## Update the website

Edit `index.html` for English content, `app.js` for French translations, and `styles.css` / `redesign.css` for styling. Commit and push to `main` to publish updates.

Put project videos and poster images in `projects/` and update the demo section. Use native video controls, captions, and no autoplay.
